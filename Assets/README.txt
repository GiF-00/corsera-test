Assets Directory
================

This directory should contain the following files:

1. manual.png - Icon for the manual menu item (16x16 or 32x32 pixels)
2. config.png - Icon for the config menu item (16x16 or 32x32 pixels)
3. app.ico - Application icon
4. manual.pdf - User manual document (optional)
5. config.txt - Configuration file (optional)

Note: The application will work without these files, but menu icons and 
file opening features will not function properly until these assets are added.

You can create simple placeholder images or use existing icons from your system.
